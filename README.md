📝 Smart Registration Form

A clean, responsive, and interactive registration form built using HTML. This project demonstrates fundamental web development concepts, semantic HTML structure, and clean user interface (UI) design.

🚀 Features

• Semantic HTML Structure: Uses modern, accessible HTML form elements, input types, and labels.
• Diverse Input Fields: Includes text inputs, email, password, date selection, dropdowns, and radio/checkbox controls.
• Built-in Validation: Utilizes HTML5 validation attributes (such as required, type="email", etc.) for immediate input checks.
• Clean & Lightweight: No heavy frameworks required—pure, fast-loading HTML.

🛠️ Tech Stack

• Markup: HTML5
• Styling (Optional/If added): CSS3
• Interactivity (Optional/If added): JavaScript
